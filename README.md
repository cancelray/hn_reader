HN Reader

Консольное приложение для просмотра новостей Hacker News. Позволяет просматривать ленты Top, New и Best, фильтровать истории, читать их содержимое и комментарии.

Запуск приложения

Требования: Python 3.10+, Poetry.

# Установка зависимостей

poetry install

# Запуск приложения

poetry run app

По умолчанию приложение обращается к официальному Hacker News API.

Можно ограничить количество загружаемых историй:
poetry run app --limit 10
limit в диапазоне 1...100

Запуск в демо-режиме

Демо-режим использует локальный mock-сервер с заранее подготовленными тестовыми историями и комментариями. Подключение к интернету не требуется.
poetry run app --demo

Для ограничения количества историй:
poetry run app --demo --limit 10

Архитектура приложения
Приложение построено по многослойной архитектуре:

UI (ui/) — пользовательский интерфейс на Textual. Отвечает за отображение лент, фильтрацию, просмотр историй и комментариев, обработку действий пользователя.

Services (services/) — бизнес-логика приложения. Управляет загрузкой историй и комментариев, ограничением количества результатов и кэшированием лент.

API (api/) — слой доступа к данным. HttpxProvider взаимодействует с Hacker News API, а Demo предоставляет локальный mock API для демонстрационного режима. BaseProvider определяет общий интерфейс провайдера.

Models (models/) — модели данных Story, Comment, Feed и обработчик HTML-текста. Отвечают за представление и преобразование полученных данных.

Config (config.py) — централизованная конфигурация приложения: адрес API, лимиты загрузки, таймауты и параметры соединения.
